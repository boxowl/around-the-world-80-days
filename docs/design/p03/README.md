# P03 · сравнение главного экрана Лондона

Статус: **три предложения для выбора, визуальное направление не утверждено**. Это один экран в трёх трактовках, без реализации в Android-коде. [Интерактивный прототип](index.html) переключает размер телефона, крупный шрифт и уменьшение анимации. Статичные превью находятся в [`exports/`](exports/); файлы `*-360x640.png` показывают сравнение на компактном телефоне, `*-412x915.png` — на высоком, `*-360x640-large.png` — стресс-тест крупного шрифта.

Во всех вариантах одна композиция: лондонская мокрая мостовая, фонари, паровой поезд у вокзала; затем участок «Лондон → Дувр», шаги сегодня, остаток до остановки и нижняя навигация «Путешествие · Карта · Дневник · Паспорт». UI-текст и цифры остаются настоящими элементами прототипа, а не частью сцены. Числа **только демонстрационные**: 2 240 шагов сегодня + 1 760 до Дувра = 4 000 шагов в демонстрации. Они иллюстрируют первый порог Дувра из `docs/ROUTE.md` ветки F01 и не меняют его; глава Лондон → Суэц остаётся 49 000 шагов. Живые данные не подключены. Отдельная метка «Демо» видна рядом с показателями.

| Направление | Сильные стороны | Риски | Дальнейшие регионы и транспорт |
|---|---|---|---|
| Книжная иллюстрация | Ближе всего к «ожившему дорожному атласу XIX века»; спокойная сцена оставляет показатели главными; палитра и фактура хорошо связывают карту, дневник и паспорт. | Тонкие детали могут теряться на маленьком экране; при большом числе сцен нужен единый художественный контроль. | Основной кандидат для Лондона, Европы, Альп, портов и Суэца. Поезд, паром и пароход можно менять в узнаваемом среднем плане; региональные палитры и 2–3 слоя позволят повторно использовать композицию. |
| Винтажный туристический плакат | Ясный силуэт, высокая узнаваемость и сильная коллекционная ценность; особенно хорош для открыток и прибытия. | Постоянный экран может стать слишком громким; плакатная типографика хуже сочетается с изменяемыми числами; тёплая сцена требует строгих подложек для текста. | Подходит для Дувра, Кале, Парижа, Суэца как открытка/награда. Поезд или пароход изображается крупным знаком; для каждого региона нужны отдельные цветовые решения. |
| Уютная игровая диорама | Транспорт выглядит предметным и близким; удобна для состояния «едем дальше» и мягкого движения. | Самый дорогой вариант по слоям и вариациям; может сместить приключенческий тон в игрушечный; плотная сцена спорит со статистикой. | Сильна для поездов, парома и парохода, смены погоды и освещения. На 10–12 базовых пейзажей потребуется больше сценовых слоёв и проверка стиля для разных культурных регионов. |

**Рекомендация для обсуждения:** книжную иллюстрацию взять основой главного экрана, плакатный язык — для открыток и штампов, а глубину диорамы — как подсказку для редких переходов транспорта. Финальное решение остаётся за пользователем; эта рекомендация не утверждает стиль.

Проверка макетов: вручную просмотрены все три варианта на **360 × 640 dp** и **412 × 915 dp**, а также компактные превью с крупным шрифтом. Сцена, маршрут, обе метрики и навигация видны; в крупном режиме метрики в прототипе переходят в один столбец, контент может прокручиваться, а нижняя навигация остаётся закреплённой. Текст поверх сцены находится на непрозрачной подложке. Расчёт контраста основных пар текста/фона: 8,0:1–12,0:1, выше 4,5:1 для обычного текста. Движение дыма декоративное; при системном `prefers-reduced-motion` или ручном переключателе оно выключается, а состояние экрана полностью читается в статике. Это проверка макетов, не Android-эмулятора и не реальных шагов.

Растровую генерацию сцены через `imagegen` попытались применить, но инструмент вернул лимит использования. Поэтому текущие сцены — оригинальные кодовые иллюстрации для сравнения направления. После выбора потребуется финальная растровая отрисовка; не считать эти превью готовыми игровыми ассетами. PNG-превью воспроизводятся скриптом `render-previews.swift` (macOS AppKit):

```sh
SDKROOT=/Library/Developer/CommandLineTools/SDKs/MacOSX15.4.sdk \
  CLANG_MODULE_CACHE_PATH=/private/tmp/p03-clang-cache \
  SWIFT_MODULE_CACHE_PATH=/private/tmp/p03-swift-cache \
  swift docs/design/p03/render-previews.swift docs/design/p03/exports
```

Основание: предложенное визуальное направление `docs/VISUAL_DIRECTION.md` и маршрут `docs/ROUTE.md` прочитаны из `feat/F01-expedition` (на момент создания P03 эти файлы ещё не были в `main`). PR P03 направлен в `main` и содержит только материалы этого сравнения, без технических веток.
