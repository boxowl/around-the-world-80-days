# V2.4a — постановка: доменная модель паспорта путешественника (read-only, для проверки штабом)

Дата: 2026-10-11. Это постановка для проверки штабом, НЕ начало реализации. Код не писать, feature-сессию не создавать до подтверждения. PR #17 открыт и не слит; PR #12/#14 не сливать.

## Цель

Доменная модель паспорта: **ровно 9 отметок** по утверждённым правилам — стартовая отметка Лондона + 8 штампов финишей глав (Суэц, Бомбей, Калькутта, Гонконг, Иокогама, Сан-Франциско, Нью-Йорк, Лондон-финал). Ключевой инвариант: **полученный штамп не отзывается** — при отрицательной корректировке прогресса, поздней замене данных, перезапуске и повторном пересечении порога штамп сохраняется и не дублируется. Модель чистая, без UI: состояние штампов как производная существующих данных, без новых сущностей наград и без миграций.

## Критерии готовности

- Модель покрывает ровно 9 отметок; ID привязаны к существующим узлам геометрии (проверка тестом существования ссылок).
- Выдача детерминирована от снимка прогресса: штамп выдаётся при достижении книжного порога финиша главы; при скачке через несколько глав выдаются все положенные; повторная выдача не дублирует.
- Откат прогресса (корректировка вниз) НЕ отзывает выданные штампы; перезапуск восстанавливает состояние из хранимых данных (предложение хранения — существующие `unlocked_diary`-совместимые записи или отдельный набор ID штампов в том же инварианте IGNORE; миграция не проектируется).
- Стартовая отметка Лондона выдаётся один раз при старте экспедиции v2.
- Дата выдачи: дата достижения по доступной истории, иначе честная дата обнаружения (без выдуманной точности).
- Старые экспедиции v1 не затрагиваются: модель не читает и не меняет их данные.
- Сборка/unit-тесты/lint зелёные; PR без автоматического слияния.

## Astra-review (обязательный)

- Инвариант неизменности штампов при откате/повторе/перезапуске — соответствует ли реализация существующим семантикам `unlocked_diary` (IGNORE) и «открытое не откатывается».
- Привязка к геометрии: пороги финишей глав вычислены из измеренной геометрии, не литералами; финиш = D.
- Границы: отсутствие изменений в запрещённых файлах, отсутствие миграций, чистота домена от UI.
