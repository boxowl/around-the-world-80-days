# Эмулятор Android на MacBook

Для разработки используется Android Emulator с ARM64-образом Android 16 (API 36, Google APIs). Имя виртуального устройства: `Expedition_API_36`.

SDK: `~/Library/Android/sdk`. Эмулятор и образ установлены отдельно от Android Studio. Локальный путь SDK хранится в игнорируемом `local.properties`.

## Повторный запуск

Откройте `scripts/run-emulator.command` двойным щелчком в Finder либо выполните из корня проекта:

```sh
./scripts/run-emulator.command
```

После загрузки Android, в другом терминале:

```sh
export JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home
./gradlew assembleDebug testDebugUnitTest lintDebug
./gradlew installDebug
```

Откройте «Вокруг света за 80 дней» в эмуляторе. Виртуальный телефон можно закрыть обычным закрытием окна. Не запускайте одновременно два экземпляра одного AVD.

## Границы проверки

Эмулятор подходит для запуска, UI, выдачи и отзыва разрешений, смены конфигурации, перезапуска и синтетических данных. Он не подтверждает точность реальных шагов, передачу с часов, энергосбережение физического телефона или задержки после прогулок. Журнал физического устройства ведётся отдельно в HEALTH_CONNECT_TEST.md.

## Результат 2026-09-13

Установлены Android Emulator 37.1.11 и образ API 36 Google APIs ARM64 revision 7. Виртуальный Pixel 7 использует Hypervisor.Framework; Android 16 загрузился, APK 0.2.0 установлен и запущен. Android Studio не установлен.

Проверено на эмуляторе:

- Холодный запуск и повторный запуск после force-stop.
- Первый запрос Health Connect: только чтение Steps.
- Отказ и повторная выдача разрешения через системный диалог.
- Успешное чтение пустого интервала: «нет данных», время чтения и пояс Europe/Moscow.
- Ручное обновление: новая отметка времени, прежнее состояние отсутствия данных; прокрутка остаётся на месте.
- Экран объяснения использования данных и возврат назад.
- Переход к управлению данными Health Connect и возврат.
- Отзыв READ_STEPS командой adb в фоне и повторный запуск: PermissionRequired, прежний результат не показывается.
- В crash-буфере ADB за эту проверку записей нет.

[Снимок экрана](screenshots/p02-emulator.png). Проверки числовых значений, поздних исправлений и повторного чтения покрыты девятью JVM-тестами; синтетические записи в сам Health Connect пока не внесены. Отзыв через UI настроек, крупный шрифт, поворот и дополнительные версии Android ещё не проверены. Реальные шаги и часы не проверены.
