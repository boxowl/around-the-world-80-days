# P07 — непрерывное путешествие (seamless journey)

Статус: реализовано в ветке `feat/P07-seamless-journey` (2026-09-20), ждёт приёмки штаба и художественной приёмки владельца. Основание — задание владельца `docs/design/KIMI_SEAMLESS_JOURNEY_PROMPT.md` (заменяет кроссфейд сцен P06 на непрерывный мир с камерой). Видеореференс недоступен текстово; спецификацией поведения служит сам промпт и решения владельца, зафиксированные в постановке задачи.

## Что изменилось по сравнению с P06

| Область | P06 | P07 |
|---|---|---|
| Рендер сцены | две сцены с alpha-кроссфейдом и разъездом по слоям | единый непрерывный мир в общих координатах, одна камера |
| Герой по горизонтали | 24 % → 76 % внутри сегмента, сброс ~52 % ширины на границе | всегда ~42 % ширины (смещение только при клампе камеры на краях мира) |
| Высота ног | интерполяция констант сцен | общий профиль рельефа `TerrainProfile`, стык по положению и наклону |
| Порт → море → Суэц | растворение сцен | причал-пандус → палуба (foreground между якорями) → берег Суэца |
| `sceneBlendAt` / `heroFractionAt` | есть | удалены вместе с закрепляющими тестами |

Оболочка, четыре вкладки, показатели, пилюля события, карта и дневник не менялись. Изменение данных и открытий дневника — по-прежнему только от подтверждённых шагов; маршрут сам по таймеру не продвигается.

## Архитектура

Новый пакет `app/src/main/java/com/boxowl/aroundtheworld/expedition/scene/`:

- **WorldLayout.kt** — мировые координаты. 1 мировая единица = высота канваса; визуальные единицы НЕ километры и не шаги. Якоря остановок равномерные: `anchorX(i) = 0.55 + i · 1.4`; поля 0.55 до Лондона и 0.6 после Суэца (мир `[0, 13.75]`). Позиция маршрута `currentIndex + fractionToNext` (из неизменённого `FirstLegMapProjection`) линейно отображается в worldX — монотонно и непрерывно через все границы; `knownSteps == null` → позиция 0. Там же `sceneMoodAt` (haze/warmth как гладкие импульсы в окне ±полсегмента — силуэты не растворяются, смещается только небо) и `sceneDescriptionAt` для contentDescription.
- **JourneyCamera.kt** — одна камера: `cameraXFor` с клампом краёв мира (`[start + 0.42·viewW, end − 0.58·viewW]`), `heroScreenFraction`, `screenFraction` с параллакс-факторами слоёв FAR 0.25 / MID 0.55 / NEAR 1.0 от одной камеры, без сбросов на границах. На типичных экранах (viewW ≤ 1.3) герой всегда ровно на 42 %; кламп срабатывает только на очень широких вьюпортах и удерживает героя в [35 %, 60 %].
- **TerrainProfile.kt** — опора под ногами: уровень земли задан один раз на остановку (0.68 суша, 0.83 палуба, 0.78 берег Суэца), smoothstep между якорями (нулевой наклон на якорях) + синусоидальный холм, затухающий у якорей и у «плоских» остановок. `groundYAt`/`groundSlopeAt` аналитичны и непрерывны; герой, заливка земли и все наземные объекты сэмплируют один профиль — герой не висит и не проваливается.
- **WorldSegments.kt** — 10 сегментов декора в мировых координатах. Процедурные генераторы (крыши, холмы, пики, телеграф, волны, облака, окна) привязаны к worldX со стабильными seed — объекты не перестраиваются между кадрами. Рисуются только сегменты в окне видимости плюс запас на параллакс дальнего слоя. Стыки конструктивные: заливка земли идёт по общему профилю; море Бриндизи и открытое море стыкуются встык на якоре a8 с одинаковой кромкой и цветом; Ла-Манш уходит за скалы слева и в дымку Кале справа; скалы заканчиваются на базовой линии. Порт → море → Суэц: причал длинным пандусом поднимается 0.68 → 0.83 к якорю a8, палуба — foreground-слой ровно между якорями a8..a9 (рейлинг, труба с дымом, мачта), у a9 палуба вровень (0.78) с берегом Суэца; канал — плоская вода за ближним берегом.
- **SeamlessJourneyCanvas.kt** — композиция. Первая композиция сразу в целевой позиции (`remember { Animatable(target) }`). Догоняющая анимация — постоянный покадровый цикл (exponential chase): постоянная времени = (250 мс + 1.75 с × расстояние) / 3, cap 2 с для больших скачков; коррекция назад — та же функция без пересоздания мира; reduced-motion → мгновенный snap. Цикл стоит на `withFrameNanos`, поэтому анимации останавливаются вне видимости и вне композиции (смена вкладки). Палитры фаз суток (`paletteFor`, лерп ±30 мин), светила и звёзды — глобальные, как в P04/P06.

`JourneyScenes.kt` сохранил палитры, `DayPhase`, светила, героя и объектные примитивы (паровоз, пароход, маяк, мачты, краны, минареты и т.д.) — они стали `internal` и переиспользуются сегментами. `JourneyHome.kt` изменён только заменой вызова на `SeamlessJourneyCanvas`. `Expedition.kt`, `FirstLegMapProjection.kt`, Room, синхронизация, Health Connect, пороги и тексты маршрута не тронуты.

## Debug-демо

Только debug-сборка (source set `app/src/debug`, в release не входит; иконки в лаунчере нет). Состояние — только в памяти: Room, Health Connect и открытия дневника не затрагиваются.

Запуск (debug APK установлен):

```sh
adb shell am start -n com.boxowl.aroundtheworld/.debug.JourneyDemoActivity
```

Экран: ползунок позиции 0..9 (с дробной частью), кнопка «Автопроход» (фиксированная визуальная скорость 0.1 позиции/с через все границы, покадровая — не зависит от тормозов записи), «Коррекция −3» (скачок назад по маршруту), переключатель «Ночь/День». Для скриптовых записей поддержаны extras: `--ef start <pos>`, `--ez auto true`, `--ez night true`, `--ei autodelay <сек>`, `--ef back <позиций>`.

## Ограничения (честно)

- Видео — ускоренная debug-демонстрация (0.1 позиции/с ≈ 700 шагов/с в базовом темпе), а не подтверждение реальных шагов; физическая приёмка P02/Q01 не затрагивается.
- Рендер — процедурный Canvas: при непрерывном движении весь мир перерисовывается каждый кадр. На эмуляторе под `screenrecord` заметных рывков в записи нет; замеров fps на физическом устройстве не проводилось — 60 fps не заявляем.
- На очень широких вьюпортах (viewW > 1.3, например разворот landscape) герой смещается с 42 % в пределах [35 %, 60 %] из-за клампа камеры; вне [0.35, 0.60] поведение не тестировалось.
- Альпы на горизонте видны заблаговременно (параллакс 0.25) — читается как «горы вдали», географически условно.
- Reduced-motion читается из системной настройки один раз на композицию (как в P06): смена настройки применится после пересоздания экрана.
- Художественная приёмка владельцем не получена; дневной Суэц по-прежнему кандидат на палитровую итерацию (унаследовано от P06).
