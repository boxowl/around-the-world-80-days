# V2.4i — прямой выбор остановки из списка

Старт: 2026-11-12. Ветка `feature/v24i-direct-stop-picker`, worktree `/private/tmp/mobile-v24i-direct-stop-picker`, база `2e3411d`. Источники: `TODO.md`, `docs/design/KIMI_AROUND_THE_WORLD_V2_PROMPT.md`, `GlobeStopCardsV1.kt`, `V2JourneyScreen.kt`, `V2JourneyUiTest.kt`.

## Цель

На карте v2 пользователь может открыть доступный список всех 25 endpoint-остановок и выбрать любую непосредственно, без последовательного нажатия «Следующая». Существующие кнопки предыдущая/следующая и переходы из паспорта сохраняются. Выбор меняет только карточку; визуальный browse глобуса и подтверждённый зачёт остаются независимыми.

## Границы

Разрешены точечные правки `V2JourneyScreen.kt`, `V2JourneyUiTest.kt`, этот документ и `TODO.md`; при необходимости — чистый тест UI-контракта. Не менять RouteDatasetV1, GlobeStopCardsV1, Room, Health Connect, PassportV1, V2MapNarrative, начисление, пороги, календарь и старый v1 UI. Прямые касания маркеров Canvas — отдельный блок после списка.

## Критерии

1. В списке все 25 карточек ровно по одному разу в порядке маршрута, включая `london#1`/`london#2`; элементы доступны TalkBack и различимы. Будущие остановки можно посмотреть, не открывая текст главы.
2. Выбор, закрытие списка и переход по вкладкам не изменяют Room/зачёт, штампы или browse. Выбранная карточка показывает верные главу, транспорт, порог, состояние и запись.
3. Instrumentation на Android 16 эмуляторе выбирает далёкую остановку напрямую и проверяет закрытый контент и неизменность метров. Полный assemble/unit/lint/release compile/instrumentation, независимое строгое read-only ревью интеграции, CI и автоматическое слияние. Физические P02/F02/Q01 отдельно.

Порядок: UI список → тест/эмулятор → строгое ревью → PR/CI/merge.
