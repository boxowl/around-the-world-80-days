# F09 — статистика сохранённых шагов за семь дней

Старт: 2026-11-10. Ветка `feature/f09-weekly-activity`, worktree `/private/tmp/mobile-f09-weekly-activity`, база `bce8f11`. Блок независим от PR #27 (Room v4) и PR #28 (освещение): оба PR уже на ревью, их код здесь не используется.

## Цель

На действующем v1-экране «Путь» показать число подтверждённых шагов за последние семь календарных дней, включая сегодня, в часовом поясе экспедиции. Рядом явно указывать, сколько дней имеют подтверждённый итог. Существующая крупная цифра «сегодня» остаётся дневной статистикой. Если ни один день не известен, показывать «нет данных», а не ноль. Явный подтверждённый ноль остаётся нулём. Игровой путь и цель главы продолжают отображаться отдельной строкой.

## Границы

Разрешены новый чистый `expedition/ActivityWeek.kt`, его unit-тест, `expedition/JourneyHome.kt` только для вывода недели, этот документ и `TODO.md`. Не менять Health Connect, синхронизацию, Room, дневник, календарь пари, расчёт v2, пороги маршрута, навигацию и визуальные сцены. Источник — сохранённая `Expedition.dailySteps`; на экране назвать это сохранёнными итогами, не обещать свежесть или физическую проверку.

## Критерии готовности

1. Окно — до семи календарных дат по `expedition.zone`, от даты старта до сегодня; сегодня включён. День до старта не считается неизвестным.
2. Сумма включает только сохранённые даты. Отсутствующий день не становится нулём; подтверждённый ноль увеличивает число известных дней. При отсутствии всех итогов сумма отсутствует.
3. Поздняя корректировка отражается в проекции без накопления, а шаги источника не смешиваются с игровым маршрутом. UI сообщает покрытие окна и дату последней успешной сверки, если она известна.
4. Unit-тесты закрывают границу недели, старт внутри недели, пояс, ноль/пропуск и замену дня. `assembleDebug`, `testDebugUnitTest`, `lintDebug` проходят. PR проходит CI; физические P02/F02/Q01 остаются открытыми.

Порядок: проверить контракты `Expedition`/`JourneyHome` → реализовать чистую проекцию и экран → unit-тесты → локальные проверки и отдельный просмотр семантики неизвестного дня → PR.

## Проверка реализации

2026-11-10: отдельный просмотр после написания кода подтвердил, что проекция использует только сохранённые даты `Expedition.dailySteps`, ограничивает окно датой старта и часовым поясом экспедиции, складывает только присутствующие значения через `Math.addExact` и сохраняет `null` для полностью неизвестного окна. Явный ноль учитывается как известный день. Коррекция заменяет значение в исходном снимке и не накапливает повторный зачёт. UI берёт игровую позицию из прежней строки главы, а новую сумму подписывает как сохранённую активность. Открыт черновой PR #29.

Локально прошли `:app:assembleDebug`, `:app:testDebugUnitTest` (4 новых теста F09) и `:app:lintDebug`. На Android 16 эмуляторе проверены запуск без разрешения Health Connect, пустое состояние «Нет данных» и покрытие 0 из 1 дня; это синтетическая визуальная проверка, не P02/F02/Q01. Сценарий с реальными шагами остаётся для физического телефона.
