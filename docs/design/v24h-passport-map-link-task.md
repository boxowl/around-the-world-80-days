# V2.4h — переход из паспорта в карточку карты

Старт: 2026-11-12. Ветка `feature/v24h-passport-map-link`, worktree `/private/tmp/mobile-v24h-passport-map-link`, база `d5fcd8c`. Источники: `TODO.md`, `docs/SPEC.md`, `docs/design/KIMI_AROUND_THE_WORLD_V2_PROMPT.md`, `PassportV1.kt`, `GlobeStopCardsV1.kt`, `V2MapNarrative.kt`.

## Цель и границы

Каждая из девяти отметок паспорта v2 открывает соответствующую выбранную карточку на вкладке «Карта». Стартовый и финальный Лондон ведут в разные occurrence. Будущий штамп ведёт к закрытой карточке без раскрытия будущего текста. Переход меняет только навигацию.

Разрешены точечное расширение чистой модели `V2MapNarrative.kt`, её JVM-тестов, `V2JourneyScreen.kt`, одного instrumentation-теста, `TODO.md` и этой задачи. Не менять Room, Health Connect, PassportV1, RouteDatasetV1, GlobeStopCardsV1, пороги/начисление, browse, календарь и старый v1 UI.

## Критерии

1. Все девять `StampId` имеют однозначный target в 25 карточках; `london#1` и `london#2` не перепутаны. Потерянная связь — fail fast в модели/тесте.
2. Кнопки доступны TalkBack и показывают текущий статус штампа. Нажатие открывает карту с нужной карточкой, не выдавая новый штамп и не меняя сохранённые метры. Будущая запись главы остаётся закрытой.
3. Unit-тесты проверяют девять связей и Лондон; emulator instrumentation — переход к ещё не полученному Суэцу и возврат к стартовому Лондону без изменений Room.
4. Assemble/unit/lint/release compile/instrumentation, независимое строгое read-only ревью межмодульной интеграции, CI и автоматическое слияние. Физические P02/F02/Q01 остаются отдельно.

Порядок: модель → UI → тесты/эмулятор → ревью → PR/CI/merge.

Проверено 2026-11-12: девять StampId ведут к уникальным occurrence; стартовый/финальный Лондон различаются. Кнопки паспорта показывают TalkBack-статус и меняют только выбранную карточку/вкладку. Unit-тесты проверяют все связи; UI-тест на Android 16 эмуляторе проверил переход к закрытому Суэцу, возврат к London#1 и неизменность сохранённых метров. Assemble/unit/lint/release compile и весь instrumentation зелёные после последней правки доступности. Независимое строгое read-only ревью межмодульной интеграции блокеров не нашло. Физические шаги не проверены.
