# P04 — спецификация атмосферных сцен главы 1

Статус: рабочая спецификация для реализации (ветка `feat/P04-atmospheric-scenes`). Основание: утверждённое направление `docs/VISUAL_DIRECTION.md` (2026-09-19), пороги `docs/ROUTE.md`. Пороги и тексты маршрута здесь не меняются и не дублируются как источник истины — сцены только привязываются к существующим порогам модели `Expedition.stops`.

## Принцип отрисовки

Сцены рисуются процедурно в Compose Canvas, растровых ассетов нет. Каждая сцена — параметризованный набор слоёв:

1. **Небо** — вертикальный градиент из 3–4 цветов, зависит от фазы суток (см. ниже). Общий для всех сцен механизм; сцена может смещать оттенок (например, морская дымка у Бриндизи).
2. **Светила** — солнце/луна и звёзды по фазе суток; позиция светила детерминирована временем.
3. **Дальний слой** — силуэт горизонта (холмы, горы, город, море), самый светлый из силуэтов.
4. **Средний слой** — характерные формы региона (скалы, крыши, мачты, пальмы).
5. **Ближний слой** — тёмный передний план: земля/дорога/палуба, объекты сцены (фонарь, поезд, паром, пароход), огни.
6. **Герой** — маленький силуэт путешественника в нижней трети; положение внутри сегмента смещается слева направо по мере шагов.

Палитра силуэтов выводится из фазы суток: ночью — почти чёрные на тёмно-синем, днём — приглушённые синевато-серые. Огни (фонари, окна, маяк) тёплые и видны в сумерках и ночью, днём гаснут.

## Фазы суток

Фаза вычисляется из `now.atZone(expedition.zone)` — пояс старта экспедиции, не пояс телефона:

| Фаза | Локальное время | Небо | Светила и огни |
|---|---|---|---|
| Ночь | 22:00–05:00 | Глубокий синий → почти чёрный | Луна, звёзды; все огни горят |
| Рассвет | 05:00–08:00 | Розово-золотой низ → синий верх | Солнце низко; огни гаснут |
| День | 08:00–17:00 | Светлый синий → бледный у горизонта | Солнце; огней нет |
| Закат | 17:00–22:00 | Терракотовый низ → фиолетовый верх | Солнце у горизонта → луна; огни загораются |

Границы фиксированные (астрономический расчёт не нужен). Переходы между фазами могут быть плавными по времени внутри часа границы.

## Переходы между сценами

Прогресс внутри сегмента `fraction = (knownSteps − from.threshold) / (to.threshold − from.threshold)`, ограничен [0, 1]:

- палитры слоёв лерпятся между сценой `from` и `to`;
- силуэты `from` уходят влево с параллаксом, силуэты `to` входят справа;
- герой движется слева направо пропорционально `fraction`;
- анимация смены состояния — стандартный easing 600–900 мс, при системном reduced-motion отключается полностью (мгновенная смена, статичная сцена).

## Контракт данных (наследуется от F04/F05)

- Пустой `dailySteps` (прогресс неизвестен) → стартовая сцена Лондона, без выдуманного движения; подпись не называет место «текущим».
- Сохранённый итог 0 → подтверждённый ноль: Лондон, герой в начале.
- Откат шагов после корректировки → сцена отступает назад; открытые записи дневника не затрагиваются.
- Прогресс за 49 000 (финиш главы) → сцена Суэца, герой в конце; дальше геометрия не растёт.
- Все числа и подписи на экране — из `Expedition`/`SyncResult`, сцена их не дублирует и не заменяет.

## Решения штаба по открытым вопросам (2026-09-19)

1. **Тёмная вся страница «Путь»**: локальная тёмная палитра внутри `JourneyHome` (фон, светлый текст, тёмные карточки). Общая строка вкладок и баннер «Новое событие» остаются светлыми — они вне зоны P04.
2. **Откат шагов**: сцена анимирует обратный переход тем же механизмом кроссфейда; отдельной логики не требуется.
3. **Неизвестный прогресс** (`knownSteps == null`): стартовая сцена Лондона в текущей фазе суток; текстовый контракт по-прежнему сообщает, что путь неизвестен.
4. **`london_book_scene.png`**: удаляется в P04 (история Git сохраняет файл; `docs/F04_VERIFICATION.md` дополняется пометкой о замене).

## Доступность

- Сцена декоративна: `contentDescription` вида «Сцена пути: Дувр, белые скалы и маяк»; вся информация доступна текстом.
- Проверка на 360×640 dp и fontScale 1.5: текстовый блок под сценой прокручивается, навигация закреплена.
- Контраст текста на тёмном фоне ≥ 4.5:1.
- Reduced-motion: сцена статична, светила и огни соответствуют фазе, переходы мгновенные.
