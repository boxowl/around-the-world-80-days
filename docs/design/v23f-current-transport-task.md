## Цель и границы

На «Пути» v2 показывать транспорт и концы текущего литературного плеча из утверждённой геометрии по подтверждённым книжным метрам. Это текстовая информация; прогресс, освещение, карта и штампы сохраняют прежние правила.

Разрешены новый чистый `expedition/globe/V2CurrentTransport.kt`, его JVM-тесты, точечный вывод в `V2JourneyScreen.kt`, один существующий instrumentation-тест, эта постановка и `TODO.md`. Не менять RouteDatasetV1, RouteMeasure, RoutePosition, Room, Health Connect, зачёт, паспорт, календарь, геометрию и debug-поток.

## Критерии

1. При 0 км показано первое плечо; при точной границе — прибывающее плечо, после границы — следующее; на/после финиша — последнее плечо и завершение. Это соответствует выбору плеча `RoutePosition.positionAt`.
2. Модель использует только `RouteDatasetV1.legs` и `RouteMeasure.cumulativeKm()`, без новых порогов/координат. Название транспорта не уточняет тип судна сверх данных маршрута.
3. Отображение зависит от подтверждённого пути, а не от browse карты; доступно через текст/семантику. Unit-тесты покрывают границы первых плеч, Суэц, финиш и откат; instrumentation проверяет текст для синтетического v2.
4. Assemble/unit/lint/release compile, emulator instrumentation, независимое строгое ревью арифметики/межмодульной интеграции, CI и автоматическое слияние. Физические P02/F02/Q01 остаются отдельно.

Порядок: модель → тесты → UI → emulator → ревью → PR/CI/merge.
