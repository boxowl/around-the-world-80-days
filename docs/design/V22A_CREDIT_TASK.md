# V2.2a — расчёт зачёта пути (постановка отдельной Kimi-задачи)

**Цель:** реализовать чистый, детерминированный расчёт книжного прогресса для *новой* экспедиции v2. Исходное расстояние за каждый календарный день приходит в виде подтверждённых целых реальных метров; сырой итог сохраняется отдельно от зачёта. Утверждённый коэффициент: 1 реальный зачтённый км = 20 книжных км. Бесплатный лимит: 1 500 реальных метров в день, применить до умножения на 20. Источник метров в этой задаче не выбирать.

**Границы:** новая ветка `feat/V22a-credit-calculation` и отдельный worktree от свежего `main`; можно менять новый чистый Kotlin-модуль `app/src/main/java/com/boxowl/aroundtheworld/expedition/credit/**`, его unit-тесты и `docs/design/v22a-credit-calculation.md`. Допускается только read-only использование `expedition/route/**` для сверки единиц и общей длины.

**Не трогать:** `Expedition.kt` версии 1, `ExpeditionDatabase.kt`/Room/миграции, `ExpeditionSync.kt`, Health Connect, UI/навигацию, `scene/**`, пороги и тексты `docs/ROUTE.md`, PR #12/#14. Не активировать покупки и не моделировать неизвестную ретроактивность права. Не сливать PR автоматически.

**Зависимости:** `TODO.md`, `docs/SPEC.md`, `docs/design/v2-route-geometry.md`, утверждение владельцем k=20 от 2026-10-09. Старые экспедиции сохраняют старые правила без пересчёта.

**Критерии готовности:**

- Чистая функция для одного дня принимает неотрицательные реальные метры и режим расчёта лимита (1 500 м или без лимита как вход функции) и возвращает сырой итог, зачтённые реальные метры и книжные метры. Умножение точно в целых единицах, переполнение обрабатывается явно, округление оставлено только представлению.
- Расчёт по дневным *заменяющим* агрегатам воспроизводим при повторном чтении и поздней корректировке, без двойного начисления. Неизвестный день отличен от подтверждённого нуля. Положительные и отрицательные корректировки меняют текущую позицию, но функция не распоряжается уже открытыми историями/штампами.
- Тесты покрывают 0, 1 500 м, превышение лимита, несколько дней, замену/повтор данных, неизвестный день, переполнение и сравнение свободного/ограниченного расчёта. Длина маршрута из PR #15 используется лишь для проверки порядка величины, не для скрытого масштабирования.
- В документе описаны единицы, формулы, границы V2.2a и нерешённые вопросы: источник реальных метров, длина шага, entitlement по дням, ретроактивность, цена и рынки. Полная сборка/unit-тесты/lint зелёные; независимое `astra-review` расчётов; PR без слияния.

**План агентов:** `terra-research` проверяет контракт календарных замен и затронутые интерфейсы read-only; `sol-implementation` реализует только указанный модуль; `astra-review` независимо проверяет арифметику, идемпотентность и совместимость старой экспедиции. Не больше двух субагентов одновременно.

**После V2.2a:** отдельная задача V2.2b подключит источник реальных метров, версионирование экспедиции и Room-миграцию после утверждения недостающих контрактов. Функциональный глобус сможет потреблять подтверждённые книжные метры без собственного расчёта баланса.
