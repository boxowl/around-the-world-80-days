# V2.3e — просмотр пройденного на пользовательском глобусе

Старт: 2026-11-12. Ветка `feature/v23e-production-browse`, worktree `/private/tmp/mobile-v23e-production-browse`, база `9218364` после PR #34. Источники: `docs/SPEC.md`, `docs/design/v2-product-decisions.md`, `V2GlobeMap.kt`, `DistanceLighting.kt`, `RoutePosition.kt`, `V2JourneyScreen.kt`.

## Цель

Пользователь может визуально вернуться к уже пройденной позиции на глобусе и одним действием вернуться к подтверждённой текущей позиции. Просмотр не меняет Room, шаги, паспорт, календарь и открытую остановку.

## Границы

Разрешены новая чистая модель `expedition/globe/V2BrowsePosition.kt`, её JVM-тесты, точечные изменения `V2GlobeMap.kt` и `V2JourneyScreen.kt`, UI-тест, эта задача и `TODO.md`. Не менять Room/DAO, Health Connect, `CreditLedger`, `RouteDatasetV1`/`RouteMeasure`/`RoutePosition`, `DistanceLighting`, паспорт, пороги, debug-прототип и Gradle.

## Критерии

1. Просматриваемые книжные метры всегда в `[0, confirmedBookMeters]` и не показывают будущее. При корректировке подтверждённого итога вниз просмотр сжимается к новой границе; при новой экспедиции сбрасывается. Нуль не даёт фиктивной навигации.
2. Глобус, герой, цвет пройденной части и затемнение используют просматриваемую позицию; для освещения отображаемые реальные км = просматриваемые книжные метры / k=20 / 1000. Подтверждённые показатели «Пути», штампы и статус карточек остаются от сохранённого snapshot.
3. Доступны понятный регулятор просмотра, подпись текущей/просматриваемой позиции и действие «Вернуться к текущей». Переход между вкладками не меняет Room. Жест вращения глобуса — отдельная задача, если не укладывается в этот срез.
4. Граничные JVM-тесты, эмуляторный UI-сценарий с синтетическими сохранёнными шагами, assemble/unit/lint/release compile и отдельное строгое ревью арифметики/межмодульной интеграции до PR и автоматического merge. P02/F02/Q01 требуют физического телефона.

Порядок: чистое ограничение позиции → локальное UI-состояние → экран и доступность → тесты/эмулятор → строгое ревью → PR/CI/merge.
