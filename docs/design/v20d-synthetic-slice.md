# V2.0d — минимальный вертикальный срез v2 (аудит и постановка)

Дата: 2026-10-12. Read-only аудит terra-research + постановка debug-only среза. Не начало кода и feature-сессии — до решения штаба.

## Факты

**В main:** `CreditLedger` (чистая модель, ×20, без сохранения и без потребителей), `RouteDatasetV1`/`RouteMeasure` (D = 40 501,8 книжных км), debug-глобус (тестовый маршрут руками, позиция героя захардкожена), мир «Пути» P07/P08 (только глава 1), v1 целиком. Прогресс v2 не потребляет ничто.

**Недостающие звенья:** (а) старт/хранение v2-экспедиции и долговечный `totalBookMeters` — нет; (б) источник метров — не утверждён; (в) **функция «точка на полилинии маршрута по дуговым книжным км» — нет нигде**, включая PR #17 (чистая геометрия, продуктового решения не требует); (г) «Путь» v2 — только данные PR #17 (неслит); (д) прод-«Карта» — нет; (е) паспорт — модель только в PR #18 (неслит), хранение — только контракт V2.4b, UI нет; (ж) навигация v2 — не начата.

**Ключевое наблюдение:** если вход — явно синтетические подтверждённые реальные метры (не шаги), то неутверждённые решения (источник метров, stride, C/D-якоря, единица освещения) не блокируют: k=20 и геометрия утверждены, позиция из книжных метров — чистая математика. Постоянный v2-старт + `daily_credit` без UI — это ядро V2.2b, безопасным блоком не является (миграции запрещены до утверждения контрактов).

## Постановка блока: debug-only вертикальный срез (V2.0d)

- **Цель:** на эмуляторе показать цепочку «явно синтетические подтверждённые реальные метры → CreditLedger → книжные метры → позиция героя и пройденная часть маршрута на debug-глобусе (маршрут из `RouteDatasetV1`, не из TEST DATA) → две колонки реальные/книжные км → маркеры 8 финишей глав из `RouteMeasure`». Постоянная пометка на экране: «СИНТЕТИЧЕСКИЕ ДАННЫЕ — тестовый контур».
- **Границы файлов:** только `app/src/debug/**` (Activity/адаптер датасета/параметр дистанции, функция позиции — в debug source set, чтобы prod не менялся вообще), `app/src/test/**` (unit-тесты функции позиции; прецедент — тесты debug-глобуса уже там), опционально `app/src/androidTest/**` — фикстура с guard `syntheticSeed=allow` + emulator fingerprint по прецеденту `SyntheticProgressSeedTest`.
- **Не трогать:** `expedition/**` вне debug (включая `route/**` на запись), Room/миграции, `health/**`, навигацию, prod UI, код PR #12/#14/#17/#18, пороги/тексты, Gradle/подпись.
- **Зависимости:** нет. Форма со штампами — после слияния PR #18 (добавление вызова `PassportV1.reconcile` отдельным инкрементом).
- **Критерии готовности:** функция позиции — unit-тесты (стыки плеч, антимеридиан, финиш = `totalKm()`, монотонность); явная маркировка синтетики на экране; ничего не пишется в Room/Health Connect; сборка/unit/lint зелёные; скриншот и видео с эмулятора; PR без автомерджа.
- **Ветка/worktree:** `feat/V20d-synthetic-slice` от main, отдельный worktree.
- **План агентов:** sol-implementation один (задача изолированная; astra-review не обязателен — нет миграций, зачёта, синхронизации; позиция проверяется числовыми тестами).
