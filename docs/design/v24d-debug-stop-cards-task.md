## Критерии готовности

1. В debug-глобусе доступен выбор любой из 25 карточек по occurrence ID; `london#1` и `london#2` различимы.
2. Выбранная карточка показывает имя, главу, прибывающий транспорт (отсутствие у старта явно), книжный порог и производное состояние достигнуто/впереди. При смене сценария состояние обновляется из нового синтетического ledger без сохранения.
3. Постоянная маркировка синтетических данных остаётся. Debug-сборка, unit и lint проходят; эмуляторный просмотр стартового и финишного сценариев подтверждён без заявления о физическом устройстве.
