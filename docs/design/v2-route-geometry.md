# V2.1b — версионируемая геометрия маршрута романа (измерение длины)

Статус: **версионируемый географический набор, версия 1, измеренная геометрия**.
Набор — измерительный инструмент, а не продуктовый контракт: k и периоды экспедиции в коде этого набора не закреплены
(константы — только `ROUTE_GEOMETRY_VERSION = 1` и радиус Земли). Заменяет
оценки черновика [v2-route-table.md](v2-route-table.md) измеренными значениями.
После завершения измерения владелец утвердил k = 20 для новых экспедиций и отменил дневной лимит; это решение фиксируется в [TODO.md](../../TODO.md).

Код: `app/src/main/java/com/boxowl/aroundtheworld/expedition/route/` — чистый
Kotlin без Android-зависимостей (`RouteModel`, `RouteGeometry`, `RouteDatasetV1`,
`RouteMeasure`). Тесты: `app/src/test/java/.../expedition/route/`
(`RouteGeometryTest`, `RouteSeaValidationTest`, `RouteWgs84CrossCheckTest`,
`RouteReportTest` — генератор этой таблицы, числа в документе из кода).

## Методика

- Модель Земли: сфера R = 6371.0 км; центральный угол через `atan2(|a×b|, a·b)`
  (устойчиво на малых дугах). Контроль: та же геометрия по эллипсоиду WGS84
  (формула Винсенти в тесте) даёт итог **40 528.9 км** против **40 501.8 км**
  на сфере — расхождение **0.067 %** (порог теста 1 %).
- Метрика: длина плеча = сумма ортодромий по полилинии узлов набора
  (воспроизводимое определение). Систематическая недооценка ж/д (−5..8 %)
  коэффициентом НЕ компенсируется — документируется в `uncertaintyPct` плеча.
- Явные исключения из метрики хорды (данные плеча, не скрытая магия):
  слон Киуни — хорда × 1.25 (объезд лесом и деревней Пилладжи); сани Маджа —
  хорда (роман прямо даёт «as the birds fly, at most two hundred miles»).
- Для каждого морского плеча хранятся `orthodromeKm` (концы) и `measuredKm`
  (по обходам); доля обхода = measured/orthodrome в таблице ниже.
- Городские стыковки (вокзал → порт) не учитываются.

## Валидация морских плеч против Natural Earth

`RouteSeaValidationTest` проверяет, что ни одно SHIP/FERRY-плечо не пересекает
сушу по данным `ne_50m_land` (Natural Earth, public domain; ассет
`app/src/debug/assets/ne_land.bin`, 616 полигонов):

- сэмплирование полилинии через slerp с шагом ≤ 0.1°;
- point-in-polygon на сфере — меридиональный ray-casting (пересечения дуг
  рёбер с меридианом точки к северу, чётность по всем кольцам, включая дырки);
  дегенеративные случаи гасятся сдвигом долготы на ε = 0.0023°;
- образцы в пределах 0.4° от узлов PORT/STOP/CALL не проверяются (порты в
  данных 50m сидят на суше; CALL добавлен осознанно — Нагасаки, заход в порт,
  бухта закрыта упрощением);
- WATERWAY-плечи (Суэцкий канал, река Хугли) не валидируются — водные пути
  ниже разрешения карты по определению;
- **список исключений пуст** — все обходы проходят по воде без исключений;
- якорные самопроверки валидатора: Париж/Дели/Сидней = суша; (0,−150),
  (−30,−45), (−20,80) = вода; Каспий (42.5, 50.5) = вода (дырка в данных).

Ограничения: разрешение 50m (проливы < ~10 км могут быть закрыты упрощением,
микро-острова < 0.35° отброшены), Каспий — дырка, порты на суше в данных.

## Итог

**D = 40 502 км, взвешенная погрешность ±4.6 %** (диапазон ≈ 38 600–42 400).
Черновик давал D ≈ 39 000 (диапазон 36 000–42 000): измерение выше на 3.9 %,
в пределах черновичного диапазона. Ожидаемые направления расхождений
подтвердились: Париж → Бриндизи завышен (−21 %), Бриндизи → Суэц (+29 %) и
Нью-Йорк → Лондон (+6 %) занижены. Дополнительно выросла строка XIX–XXIII
(+16 %): обход островов Гото с заходом в Нагасаки и огибание Японии с юга
заметно длиннее прямой.

## Оценка гипотезы k = 20

T = D / (k · r): при D = 40 502, k = 20, r ≈ 5.5 км/сут → **T ≈ 368 суток**
(год + 3 дня). С учётом погрешности D: T ≈ 351–385 суток. Гипотеза k=20
**согласуется** с годичным циклом при r ≈ 5.5 км/сут (идеальное совпадение
было бы при r ≈ 5.54 км/сут). Решение о закреплении k — за штабом/владельцем.

## Открытые вопросы для штаба

- Конвенция Кхолби (25.30, 81.10): вымышленная точка романа, поставлена по
  условию «~50 миль до Аллахабада по линии GIPR, юго-западнее» — утвердить
  как литературную конвенцию набора.
- Нагасаки как CALL (заход без остановки сюжета); валидация пропускает 0.4°
  вокруг CALL наравне с PORT/STOP.
- Солт-Лейк-Сити исключён из длины (экскурсия, гл. XXVII) — длина считается
  по транзиту СФ → Огден.
- Метрика ж/д — полилиния станций без поправочного коэффициента; недооценка
  ~5–8 % сидит в `uncertaintyPct`. На Огден → Форт-Керни недооценка выходит за
  типичную вилку: измерено 1 128 км при реальной линии UP вдоль Платта
  ~1 300 км (разрыв ~15 %), поэтому плечо несёт `uncertaintyPct = 15` и
  является кандидатом на добавление узлов вдоль Платта в версии 2 набора.
- Суэцкий канал (WATERWAY Порт-Саид → Суэц): полилиния из трёх узлов даёт
  149.6 км при реальной длине канала ~193 км (недооценка ~22 %), поэтому
  плечо несёт `uncertaintyPct = 25`; река Хугли — та же природа погрешности.
- Числа миль в романе ненадёжны (роман: Суэц → Аден «1310 миль» против
  измеренных 2 437 км ≈ 1514 миль) — калибровка только по геометрии.
- Измеренная D = 40 502 км при утверждённом k = 20 даёт T ≈ 368 суток при
  личном темпе r ≈ 5.5 км/сут без дневного лимита.
