# R01 · иконка запуска

Статус: кандидат для альфы; художественная приёмка владельцем остаётся открытой.

## Задача и границы

- Цель: убрать системную иконку по умолчанию и дать приложению узнаваемый значок запуска.
- Ветка `feature/r01-launcher-icon`, отдельный worktree от `origin/main` (`654ad80`).
- Разрешены только manifest, ресурсы иконки, эта заметка и запись в TODO.
- Не менять сцены, продуктовые правила, Room, Health Connect, разрешения, версию или подпись.
- Зависимость: тёмное визуальное направление P03/P06; цвета `#05080C`, `#D9A441`, `#F2EAD8` взяты из `MainActivity.kt`.

## Реализация и проверка

Векторный глобус с линией маршрута помещён в безопасную центральную область adaptive icon. Это рабочий значок для альфы, без сторонних ассетов. Для релизной R01 нужна художественная приёмка и полный комплект магазинных материалов.

Критерии: ресурс разрешается Android сборкой; lint не сообщает `MissingApplicationIcon`; на эмуляторе значок виден в лаунчере без обрезания; остальные проверки сборки и unit остаются зелёными. Исследование — manifest и текущая палитра; реализация — ресурсы и manifest; ревью — визуальная проверка APK на эмуляторе и lint.

Проверено локально на Pixel 7 / Android 16: `assembleDebug`, 92/92 unit-теста, `lintDebug` (0 ошибок, нет `MissingApplicationIcon`). APK установлен на эмулятор, иконка видна целиком в списке приложений: [снимок экрана](../screenshots/r01-launcher-icon.png). Это не художественная приёмка и не готовность к публикации.
