# P08 — художественное качество двух фрагментов (HQ visual)

Статус: реализовано в ветке `feat/P08-hq-visual` (2026-09-21), ждёт приёмки штаба и владельца. Основание — штабное ревью P07 `docs/design/P07_HQ_VISUAL_REVIEW.md`. Непрерывный мир P07 сохранён: координаты, камера, якоря, стыки и модель данных не переписывались; изменён визуальный слой и политика анимации камеры.

## Что изменено по сравнению с P07

| Область | P07 | P08 |
|---|---|---|
| Догонялка камеры | exponential chase без дедлайна (~95 % за 2 с, остаток ~5 % пути), цикл просыпается каждый кадр | `ChaseAnimation`: ease cubic-out, точный snap к цели ≤ 2 с (250 мс + 1.75 с/позицию); в покое цикл спит на `snapshotFlow` до новой цели; reduced-motion — snap + сон |
| Системная строка | `enableEdgeToEdge()` по системной теме — тёмные значки на тёмном фоне | `SystemBarStyle.dark` в обеих activity — светлые значки |
| Деревья/пальмы/ели/кипарисы | идентичные геометрические примитивы | `scene/Silhouettes.kt`: seed-вариативные силуэты (seed = worldX): изломанный ствол и крона 6–9-точечным бéзье из 2–3 подмассивов, ярусная ель, кипарис с несимметричными сторонами, пальма с перистыми листьями (спина + листочки) |
| Пароход | прямоугольный корпус + труба | носовой обвод с подъёмом, два яруса надстройки и мостик, наклонная труба с полосой, вентиляторы, мачты с тросами, иллюминаторы (ночью тёплые), ватерлиния |
| Облака | три прозрачных круга, только над морем | слоистые вытянутые банки (2–3 сплющенных контура, seed) в небе seg0–seg2 и seg8 |
| Холмы дальнего плана | гладкие повторяющиеся дуги | риджи с отрогами (второй хребет) и лесистыми зубцами на гребне |
| Скалы Дувра | 6-точечный полигон | составной меловой массив: зубчатый гребень с редкими выемками, 3 стратификационные линии (клип по силуэту), затенённая подошва; края a2+0.1..a2+1.0 и база 0.68h сохранены |
| Рельеф суши | один синус, амплитуда 0.008 | многочастотные холмы (3 гармоники, джиттер амплитуд по сегментам, пик ~0.02) с затуханием значения и наклона у каждого якоря; аналитическая непрерывность `groundYAt`/`groundSlopeAt` сохранена |
| Дорога/телеграф/забор | прямая лента, ровный ритм столбов | извилистая дорога по профилю; телеграф с разорванным ритмом, наклоном и пропусками; забор с неровными столбами и просветами; копны/кусты/камни с seed |
| Герой | статичная поза, скользит при движении | `WalkCycle`: фаза шага от ΔworldX (STRIDE_WORLD 0.045), gait — сглаженная скорость (~150 мс атака/затухание); размах ног ∝ sin(2π·phase)·gait, bob корпуса, посох в противофазе; в покое стойка; назад — фаза вспять |
| Посадка | пандус, залитый как земля (0.68→0.83) | плоский каменный причал → трап-конструкция (настил, поперечные доски, перила) на сваях, под ним открытая вода; пароход рейда продлён ровно до a8 |
| Палуба | полоса `near`, залитая до низа | борт судна: палубная кромка по профилю, скруглённые нос у a8 и корма у a9, иллюминаторы, ватерлиния; ниже открытая вода с 2 рядами гребней и бликами; герой стоит (gait = 0), плавание создаёт движение мира |
| Профиль уровней | smoothstep на весь сегмент (склон-холм) | ledge-переходы: подъём только на последних 0.5 wu перед a8, спуск на последних 15 % перед a9; берег за a9 ровный 0.78 |

Новые контракты: `ChaseAnimation.planDurationMs/chaseValueAt`, `WalkCycle.advancePhase/gaitAt`, `TerrainProfile.supportAt` (LAND / PIER_RAMP / DECK / BANK), `TerrainProfile.rampStartX`. `Expedition.kt`, `FirstLegMapProjection.kt`, `ExpeditionSync.kt`, `HealthConnectStepsGateway.kt`, `ExpeditionViewModel.kt`, пороги, Room, Health Connect и `docs/ROUTE.md` не тронуты.

## Ограничения (честно)

- Художественный эталон сделан для двух фрагментов (Лондон→Дувр, Бриндизи→Суэц); остальные остановки получили только глобальные улучшения (силуэты, облака seg0–2, риджи, рельеф, ходьба). Распространение эталона на все остановки — следующая итерация по решению владельца.
- Видео — debug-демонстрация с ускорением; screenrecord на этом эмуляторе пишет ~1.5–2 кадра/с, поэтому плавность оценивается по покадровой сетке, а не по fps. 60 fps не заявляем.
- «Жизнь» воды/дыма/бликов — только от движения камеры (фаза от worldX): в покое мир полностью статичен по решению штаба; блики привязаны к мировым координатам, а не к экранному положению светила.
- Стратификация скал — рисованные линии внутри силуэта, не текстура; на больших экранах может читаться как контурная графика.
- Скалы Дувра в MID-слое (параллакс 0.55) — при движении камеры их сдвиг относительно берега заметен; композиционно принято как «дальний массив».
- Трап и нос корпуса стыкуются в мировых координатах у a8; на отдельных кадрах возможен пиксельный зазор между настилом трапа и палубной кромкой из-за округления.
- Ходьба на трапе обычная (без замедления на подъёме); на палубе шаг отключён полностью, включая пересечение палубы при коррекции назад.
- Художественная приёмка владельцем не получена.
